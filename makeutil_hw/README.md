## Overview
Проект демонстрирует автоматизацию разработки с помощью Make.

## Structure
- src/ — исходный код
- scripts/ — вспомогательные скрипты
- Makefile — автоматизация

## Quick start

### Without Make (manual)
1. python3 -m venv .venv
2. source .venv/bin/activate
3. pip install -r requirements.txt
4. python src/app.py

### With Make
make install

## Available commands
make help
