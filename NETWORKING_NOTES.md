# Сетевое взаимодействие в Docker

## 1. Локальный запуск (без Docker)

Если сервисы запущены на хосте:

http://127.0.0.1:8001 → product-service  
http://127.0.0.1:8003 → discount-service  

Здесь localhost = ваша машина.

## 2. НЕУДАЧА в Docker (127.0.0.1 внутри контейнера)
Если внутри контейнера указать:
http://127.0.0.1:8001

Это ошибка потому что:
- 127.0.0.1 внутри контейнера = сам контейнер
- другие сервисы недоступны

## 3. УСПЕШНОЕ взаимодействие контейнеров

В Docker Compose:
http://product-service:8000  
http://discount-service:8000  

Docker DNS сам резолвит имена сервисов.

## 4. ДОСТУП через хост (host.docker.internal)

Иногда можно:
http://host.docker.internal:8001

Используется когда:
- контейнер → хост-сервис
- скамит чистый линукс

## Главный вывод

> 127.0.0.1 всегда относится к текущему окружению выполнения.

- на хосте → это хост
- в контейнере → это контейнер
- между контейнерами → только имена сервисов
